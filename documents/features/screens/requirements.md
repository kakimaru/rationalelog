# 画面構成と遷移

## 方針
- アプリの画面は 3 つだけにする（ほかにサービス紹介の LP を 1 つ持つ）。記録（入力 → 振り分け → 深掘り）はホームの中で完結させ、画面を移動させない
- 振り分け・深掘り・ログ編集・削除確認はモーダルで出す
- ルーティングライブラリは使わない。`location.hash` を読む小さなフック（`src/lib/useHashRoute.ts`）で画面を切り替える
  - 理由：パッケージを追加せずに、ブラウザの戻る・リロード・URL 共有に対応できる。静的サイトのまま Vercel に置ける（rewrite の設定が要らない）

## ルート

| URL | 画面 | ファイル（案） |
|---|---|---|
| `#/` | ホーム | `src/pages/HomePage.tsx` |
| `#/projects/:projectId` | プロジェクト詳細 | `src/pages/ProjectPage.tsx` |
| `#/case-studies/:caseStudyId` | ケーススタディ編集 | `src/pages/CaseStudyPage.tsx` |
| `#/about` | このサービスについて（LP） | `src/pages/AboutPage.tsx` |

- 該当しない URL や、存在しない ID の場合は「ページが見つかりません」と表示し、ホームへのリンクを出す
- ハッシュが空の場合は `#/` として扱う

## 画面ごとの構成

### ① ホーム（`#/`）
- `lg` 以上では2カラム（左 2/3：記入と最近のログ ／ 右 1/3：プロジェクト）。`lg` 未満では縦に積む
- 入力欄（ログ作成）… 詳細は `features/log/requirements.md`
- 最近のログ。見出しの横の切り替え（リスト／カレンダー）で表示を変える。切り替えは保存しない（初期表示はリスト）
  - リスト：新しい順に 10 件まで。各ログにプロジェクト名・種別・日付・深掘り済みかどうかを表示する
  - カレンダー：月表示（日曜はじまり、初期表示は今月）。前月／翌月／今月へ移動できる。ログがある日はドットと件数を出し、今日は枠線で示す。すべてのログを対象にする
    - ログがある日にホバーまたはフォーカスすると、その日のログを最大 3 件（種別・プロジェクト名・本文 2 行まで）と「ほか n 件」をポップオーバーで出す
    - 端の列ではポップオーバーが画面外に出ないよう、左右の寄せ方を変える
- プロジェクト一覧（カード、1列）。名前・ログ件数・深掘り済みの件数を表示する。押すとプロジェクト詳細へ移動する
- 「プロジェクトを追加」ボタン（右カラムの見出しの横）
- 空の状態：左カラムに「今日やったことを一言書いてみましょう」というガイドと、「サンプルデータを入れる」ボタン

### ② プロジェクト詳細（`#/projects/:projectId`）
- プロジェクト名・説明・キーワード（編集・削除できる）
- ログ一覧（新しい順）。種別で絞り込める。各ログから編集・削除・深掘りができる
- ケーススタディ一覧。押すとケーススタディ編集へ移動する
- 「ケーススタディを作る」ボタン … 詳細は `features/case-study/requirements.md`

### ③ ケーススタディ編集（`#/case-studies/:caseStudyId`）
- `lg` 以上では2カラム（左：入力フォーム ／ 右：スライドのプレビュー）。プレビューはスクロールしても見えるよう固定する
- 6 つのセクション（背景 / 課題 / プロセス / 判断理由 / 成果 / 学び）を、それぞれテキストエリアで編集する
- 元にしたログの一覧（参照用、折りたたみ。左カラムの下）
- 保存・削除・プロジェクト詳細へ戻る
- スライドのプレビュー … 詳細は `features/case-study/requirements.md`

### ④ このサービスについて（`#/about`）
- サービスの価値とビジネスモデルを説明する LP … 詳細は `features/about/requirements.md`

## 遷移図

```
ホーム ──(プロジェクトカード)──▶ プロジェクト詳細 ──(ケーススタディを作る → 生成)──▶ ケーススタディ編集
  ▲                                │  ▲                                                │
  └───────────(戻る)────────────────┘  └──────────────────(戻る)──────────────────────────┘
```

## 共通レイアウト
- ヘッダー：サービス名（押すとホームへ移動）と、ナビ「このサービスについて」（表示中は `aria-current="page"`）
- 中身の幅は画面ごとに切り替える：プロジェクト詳細・404 は `max-w-4xl`、ホーム・ケーススタディは `max-w-6xl`、LP は全幅（各セクションの中身は `max-w-6xl`）
- ヘッダーの下に「デモ版：データはこのブラウザにだけ保存されます」と表示する
