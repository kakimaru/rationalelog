# このサービスについて（LP）

URL：`#/about`（ヘッダーのナビ「このサービスについて」から移動する）

## 目的
- サービスの価値（記録 → 深掘り → ケーススタディ → 発表資料）とビジネスモデルを、一般的な Web サイトの LP の形で説明する
- 文言はサービス紹介の固定テキストなので、`src/pages/AboutPage.tsx` の中に定数として持つ（AI の応答ではない）

## セクション（上から順に）
1. ヒーロー：キャッチコピー「書き溜めた断片が、そのまま語れる実績になる」、説明文、CTA「無料ではじめる」（→ `#/`）、アプリ画面のイメージ（画像ではなく UI 部品の見た目で描く）
2. 課題提起：判断の理由を思い出せない／経緯が散らばる／記録が続かない（`concept.md` の課題から）
3. 機能紹介 Point 01〜03：30 秒で記録／AI の問いかけで深掘り／ケーススタディとスライドにまとめる。`lg` 以上では文章とイメージを左右交互に並べる
4. 使い方 3 ステップ：記録する → 深掘りする → まとめる
5. 料金プラン：Free / Pro（おすすめ）/ Team。価格と内容は `concept.md` の表のとおり
6. FAQ：`details` / `summary` で開閉する（データの保存先、AI の扱い、守秘案件、記録の頻度）
7. 最終 CTA
8. フッター：サービス名とデモ版の注記

## 料金表示の扱い
- 表示のみで、課金機能は作らない。「※ デモ版のため価格は仮です。課金機能はありません。」と書く
- Free のボタンはホームへ移動する。Pro / Team のボタンは無効の「準備中」にする

## レイアウト
- 参考：余白・文字サイズ・コンテンツの順番は ADAY（https://aday.hitotabi.design/）、要素の幅は penmark（https://penmark.jp/）
- セクションの上下：`py-24`（96px）。ヒーローと最終 CTA は `py-32`（128px）。penmark のセクション余白 120〜160px に最も近いトークン
- 中身の幅：`max-w-6xl mx-auto px-6`（penmark のコンテナ幅 1200px に最も近い）。文章だけのブロックは `max-w-3xl`
- 見出し：ヒーロー `text-4xl`、セクション見出し `text-3xl`、カード見出し `text-xl`、本文 `text-lg leading-relaxed`（type scale の最大が `4xl` のため、それより大きくしない）
- 背景は `bg-surface-raised` と `bg-bg` を交互にしてセクションを区切る。最終 CTA だけ `bg-primary-800` にして締める
